# xu-chaommvb-notes

Mobile developer · Kotlin and Jetpack Compose

给自己省点事的小工具

## 用法

```bash
cat data.txt | node index.js
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/xu-chaommvb-notes.git
cd xu-chaommvb-notes
npm install
```
